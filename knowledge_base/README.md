# ナレッジベース ノート追加ガイド

このフォルダに Markdown ファイル（`.md`）を追加すると、RAG（ベクトル検索）の対象になります。

## フォーマット

- 1ファイル1トピックを推奨（例: `fast8.md`, `interest_management.md`）。
- 見出し（`#`, `##`）単位でチャンク分割されるため、意味の区切りごとに見出しを付けてください。
- 特別なフロントマターは不要です。通常のMarkdownとして記述してください。

```markdown
# ファスト8の手順

## 目的
...

## 具体的な手順
...
```

## ノートを追加した後の反映方法

ノートを追加・編集したら、以下のコマンドでベクトルDB（ChromaDB）を再構築してください。

```
python scripts/build_vector_db.py
```

再構築後、アプリ（`streamlit run app.py`）を再起動すると新しい内容が検索対象に反映されます。
